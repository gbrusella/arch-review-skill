# Security policy

This repository contains a skill: Markdown instructions and JSON manifests, with no executable code. The security-relevant risks are in the instructions themselves, for example wording that could lead an AI agent to print secret values, write to the reviewed project, or run commands it should not.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include which file and instruction is affected and what an agent could be led to do. You can expect an acknowledgement within a few days.

## Supported versions

Only the latest tagged release receives fixes.
