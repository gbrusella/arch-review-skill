# Regulated data

Applies only if PHI, PII, or other regulated data is indicated.

- Is regulated or sensitive data in scope? Do the organizations and data flows make a specific regulation (for example HIPAA) applicable?
- Check for documented safeguards, access controls, auditability, retention/disposal, breach process, and required agreements (for example a BAA).
- Never give a legal determination or declare a system compliant. Identify evidence gaps for qualified privacy, security, or compliance review.
