# NFRs

Look for a measurable target and a verification method for each relevant quality:
performance/latency, throughput, concurrency, availability, scalability, resilience,
RTO/RPO, accessibility, maintainability, supportability, cost.

- Flag vague goals ("fast", "highly available") as `doc-gap`.
- Mark each target as **stated** (in a document) or **recommended** (your suggestion). Never blur the two.
